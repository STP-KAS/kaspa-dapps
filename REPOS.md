## Why this cut

A builder asked to “summarise all repos, it is a mess.” Growing another encyclopedia would add object 45 to the pile.

Criteria for **keep**:

1. A dApp developer can run it, or it states a law tests can fail.
2. It has a single job. Duplicates lose.
3. Upstream is cited when we are not the authors.
4. Dollar-named work is labelled candidate / classroom / guest — never money.

Criteria for **archive**:

1. Pass log of a freeze already recorded.
2. Second till, second 402, second KaChat, second names kit.
3. Overlay of Parker that should have been a PR or a local branch.
4. Fork treated as if it were the source.

Renames considered and **not** done: renaming 30 repos in one day would break every existing link. This map is the rename. Optional later: archive-flag the archive table on GitHub (Settings → Archive) once you are sure nothing in them is the only copy of a txid.
